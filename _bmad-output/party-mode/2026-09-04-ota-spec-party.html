The night the OTA spec grew teeth

Denys Zhmachenkov · 2026-09-04 · installed cast · session mode

What stuck

  • GitHub Releases + manifest.json poll — not URL-in-Install, not lab OTA CA.
  • Public CA roots; MQTT CA stays MQTT-only.
  • ~1.96 MiB dual slots; build gate slot − 256 KiB.
  • HA state JSON: versions + mid-download progress; fixed payload_install.
  • Poll B: 12h + MQTT-up, 1h min gap; SoftAP / in-flight OTA suppress.
  • Confirm = s_mqtt_session_ready; 15 min pending → restart → rollback.
